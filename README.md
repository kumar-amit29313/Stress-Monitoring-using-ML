📊 Student Stress Level Prediction

A machine learning project to analyze, model, and predict stress levels among students using survey data. Includes detailed EDA, visual dashboards, feature importance analysis, and actionable insights.

🚀 Project Highlights

✅ Dataset: Real-world student stress dataset with psychological, academic, and social features.

📈 Models Used: Random Forest, Logistic Regression

🧠 Top Features: Anxiety, depression, sleep quality

🎯 Best Accuracy: 87.3% (Random Forest)

🛠️ Tools & Libraries

Python, Pandas, Numpy, 
Seaborn, Matplotlib, 
Scikit-learn

Jupyter Notebook

📊 Visual Insights

Stress distribution pie chart

Correlation heatmap of key stress factors

Category-wise analysis (Psychological, Academic, Social, etc.)

🧠 Key Findings

Psychological factors are the strongest stress predictors.

Poor sleep and academic pressure increase stress risk.

Social support reduces likelihood of high stress.

💡 Recommendations

For Students: Focus on sleep, mental wellness, time management.

For Institutions: Offer mental health programs, reduce academic overload.
